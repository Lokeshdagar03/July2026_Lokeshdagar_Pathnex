# Production EKS Platform

## Overview

A production-grade DevOps project built on AWS using Infrastructure as Code, Kubernetes, GitOps, CI/CD, monitoring, and security best practices.

## Technology Stack

- AWS
- Terraform
- Amazon EKS
- Docker
- Kubernetes
- Helm
- ArgoCD
- GitHub Actions
- Prometheus
- Grafana

## Project Goals

- Infrastructure as Code
- GitOps Deployment
- Secure AWS Authentication
- Monitoring & Alerting
- Automated CI/CD

## Architecture

GitHub → GitHub Actions → Terraform → AWS EKS → Helm → Kubernetes

## Features

- Infrastructure as Code
- GitOps deployment
- Monitoring
- Security Best Practices
- CI/CD Automation
